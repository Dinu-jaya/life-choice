# 🎮 Life Choice Simulator

A story-based interactive web game where your decisions shape your future.

## 🚀 Concept

Life is a series of choices. This project simulates how small daily decisions (study, procrastination, networking, etc.) affect your:

* 📈 Skills
* 💰 Money
* 😊 Happiness

Every choice leads to a different life outcome.

---

## 🎯 Features

* 🔀 Multiple endings (Success / Average / Burnout)
* 📊 Real-time stats tracking
* 🎭 Interactive decision making
* ⚡ Dynamic story progression
